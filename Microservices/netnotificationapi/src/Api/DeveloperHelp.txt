Step 2:

The authorization_code that the app requested. The app can use the authorization code to request an access token for the target resource. 
Authorization_codes are short lived, typically they expire after about 10 minutes.
Now that you've acquired an authorization_code and have been granted permission by the user, you can redeem the code for an access_token to the desired resource. 
Do this by sending a POST request to the /token endpoint:
